## 1. Резюме

**«Під склом»** перетворює фразу користувача на мем із картини українського художника, що перебуває в суспільному надбанні, і показує коротку перевірену історію про картину та митця. Працює як сайт і як Telegram-бот, без обов'язкової реєстрації.

| | |
| :-- | :-- |
| **Місія** | Наблизити людей до українського мистецтва через гумор |
| **Продукт** | Сайт + Telegram-бот: «Фраза → Картина» та «Картина → Підпис», редактор, історії, сторінки художників, «Мої меми» |
| **Аудиторія** | Україномовні користувачі 16–35 років, які щодня діляться мемами в месенджерах; далі вчителі, музеї, SMM-команди |
| **Головна перевага** | Меми з українського мистецтва + перевірені факти (AI не вигадує історію) + юридично чистий контент (тільки public domain) |
| **North Star Metric** | Кількість **завершених мемів на тиждень** (завантажених, поширених або збережених) |
| **Модель доходу** | B2B-партнерства з музеями та брендами, гранти на культуру, мерч на вимогу, освітні пакети, преміум-функції |
| **Вартість запуску** | Близько нуля на старті: безкоштовні тарифи Vercel, Render, Supabase; єдина змінна витрата — виклики AI |
| **Мета на 12 місяців** | Гіпотеза: 25–40 тис. завершених мемів на тиждень, 3–5 платних B2B-партнерів, вихід на операційну самоокупність |

**Чому це може вирости саме зараз:**

- Попит на українську культуру та українськомовний контент після 2022 року суттєво зріс; музеї шукають цифрові способи говорити з молодою аудиторією.
- Telegram є одним з основних каналів комунікації в Україні, а мем є найприроднішим форматом для поширення в ньому.
- Vision-моделі зробили якісний підбір картини за емоцією та ситуацією дешевим (центи за запит) без навчання власних моделей.
- Кожен мем із водяним знаком є безкоштовною рекламою продукту: розповсюдження вбудоване в сам продукт.

## 2. Проблема та можливість

### Проблеми

| Для кого | Проблема |
| :-- | :-- |
| **Звичайні користувачі** | Українське класичне мистецтво сприймається як «шкільна програма» і «музейна тиша»: далеке, серйозне, не про моє життя. Більшість знає Шевченка як поета і майже не знає його картин, а імена Пимоненка, Мурашка чи Нарбута мало кому щось говорять. |
| **Автори мемів** | Мем-шаблони здебільшого іноземні. Українських за візуальним кодом мало, а класичні мем-шрифти часто не підтримують кирилицю («ґ є і ї»). |
| **Музеї та культурні інституції** | Мають оцифровані колекції, але не мають інструменту, який робить їх вірусними. SMM робиться вручну, молода аудиторія не доходить. |
| **Вчителі** | Потрібні способи зацікавити учнів мистецтвом та історією у форматі, який підлітки споживають добровільно. |
| **Бренди та SMM** | Потрібен впізнавано український, юридично безпечний візуальний контент для ситуативного маркетингу. |

### Можливість

Мем є форматом, яким люди діляться добровільно і щодня. Якщо до кожного мема прикріпити один несподіваний факт («цю банкноту намалював Нарбут», «модель для картини — донька художника»), розважальна дія стає точкою контакту з культурою. Користувач приходить по жарт, а йде з історією.

Класичні картини вже довели свою мем-придатність у світі (формат «classical art memes» існує понад 10 років), але українського продукту з власною колекцією, AI-підбором і перевіреними фактами немає.

## 3. Рішення та ціннісна пропозиція

### Що вже є в продукті

- **Фраза → Картина.** Користувач пише фразу чи ситуацію, AI підбирає картину за **емоцією та ситуацією**, а не за предметами («Коли дедлайн завтра» знаходить стривожене обличчя, а не годинник).
- **Картина → Підпис.** Користувач обирає картину, AI пропонує 3 підписи в різних стилях.
- **Редактор підпису**: позиція, шрифт (5 кириличних), розмір, колір, обведення.
- **Історія під мемом**: факт про картину, факт про художника, посилання на сторінку митця.
- **Художники**: біографії, факти, усі роботи з кнопкою «Зробити мем».
- **Мої меми**: збереження після входу (Google або magic link).
- **Telegram-бот** з обома сценаріями.

### Ціннісна пропозиція за сегментами

| Сегмент | Що отримує |
| :-- | :-- |
| Користувач | Смішний, унікальний, український мем за 10 секунд + цікавинка, якою хочеться поділитися |
| Музей | Нова молода аудиторія для колекції, статистика популярності робіт, готовий інтерактив для сайту й соцмереж |
| Вчитель | Готова вправа для уроку: учні роблять мем і пояснюють картину |
| Бренд | Український ситуативний контент без ризику авторських претензій |

### Що важко скопіювати

1. **Курована база «мем-профілів».** Кожна картина має вручну перевірений профіль: що зображено, емоції, 5–8 побутових мем-ситуацій, позначки чутливості. Це місяці редакторської роботи, а не один запит до моделі.
2. **Перевірені факти.** AI лише обирає факт із таблиці, де кожен запис має джерело і підтвердження другою людиною. Це знімає головний ризик AI-продуктів у культурі, а саме вигадану історію.
3. **Дані про гумор.** Логи «фраза → кандидати → обрана картина → чи замінив → чи зберіг» з часом дають унікальний датасет: які картини й ситуації реально смішні для українців.
4. **Юридична чистота.** Лише автори, що померли у 1955 році або раніше; для кожного зображення зберігаються ліцензія і джерело. Це дозволяє комерційне використання, включно з мерчем.
5. **Бренд і тон.** «Добрий гумор», музейна візуальна мова, українська мова за замовчуванням.

## 4. Цільова аудиторія

### Сегменти

| # | Сегмент | Опис | Пріоритет |
| :-- | :-- | :-- | :-- |
| S1 | **Мем-комунікатори** | 16–30 років, студенти й молоді фахівці; щодня шлють меми в чати друзів, одногрупників, колег | Ядро, старт |
| S2 | **Культурно зацікавлені** | 22–40 років; ходять на виставки, читають Ukraїner, «Локальну історію», підписані на культурні канали | Старт |
| S3 | **Автори контенту й SMM** | Адміни Telegram-каналів, SMM-менеджери брендів і медіа; потрібен регулярний контент | 3–6 місяців |
| S4 | **Вчителі** | Мистецтво, історія, українська література, НУШ; шукають інтерактив | 3–6 місяців |
| S5 | **Музеї та інституції** | Платники B2B: музеї, фонди, культурні центри | 6–12 місяців |
| S6 | **Діаспора** | Українці за кордоном; інструмент культурного зв'язку та самопрезентації | 12+ місяців |

### Персони

**Оля, 20 років, студентка.** Сидить у п'яти групових чатах. Хоче відповісти на повідомлення старости чимось, чого ще ніхто не бачив. Мистецтвом не цікавиться, але «прикольний факт» перешле подрузі. *Робота, яку вона наймає продукт виконати:* «допоможи мені смішно й оригінально відреагувати за 15 секунд».

**Андрій, 29 років, SMM-менеджер.** Веде сторінку кав'ярні чи IT-компанії. Потрібен ситуативний контент щотижня, боїться авторських претензій. *Робота:* «дай мені впізнавано український візуал, який можна публікувати від імені бренду».

**Пані Ірина, 41 рік, вчителька мистецтва.** Діти нудьгують на темі «український живопис XIX століття». *Робота:* «дай мені 15-хвилинну активність, після якої учні запам'ятають три картини».

**Марія, 34 роки, менеджерка комунікацій музею.** Має оцифровану колекцію і нульовий бюджет на розробку. *Робота:* «зроби так, щоб про наші картини говорили в соцмережах, і дай мені цифри для звіту».

## 5. Ринок

Оцінка «згори вниз». Усі вхідні числа є **припущеннями, які треба перевірити за відкритими джерелами** (DataReportal, Kantar, Держстат, дослідження Gradus/КМІС) перед пітчем.

| Рівень | Як рахуємо | Орієнтир |
| :-- | :-- | :-- |
| **TAM** | Україномовні інтернет-користувачі в Україні та діаспорі | ~25–30 млн осіб |
| **SAM** | Користувачі 16–40 років, активні в Telegram та Instagram, які діляться розважальним контентом | ~8–10 млн осіб |
| **SOM (12–18 міс.)** | Частка SAM, якої реально досягти органікою, ботом і партнерствами | 1–2% SAM, тобто 100–200 тис. унікальних користувачів |

**B2B-ринок (оцінка «знизу вгору»):**

- Музеї, галереї, заповідники з оцифрованими колекціями: сотні інституцій в Україні, з них кілька десятків мають активні комунікаційні команди. Реалістична ціль на перший рік: 3–5 пілотів.
- Грантові програми для культури та цифрових проєктів (УКФ, House of Europe, програми ЄС, міські конкурси). Типовий розмір гранту для цифрового культурного проєкту суттєво перевищує річні витрати продукту на інфраструктуру.
- Бренди з ситуативним маркетингом українською: ритейл, банки, телеком, FMCG.

**Що перевірити:** кількість музеїв з публічними цифровими колекціями; актуальні грантові конкурси та дедлайни; охоплення Telegram серед аудиторії 16–35.

## 6. Конкуренти та диференціація

| Гравець | Що робить | Чого не має |
| :-- | :-- | :-- |
| Генератори мемів (Imgflip, Kapwing, Canva) | Шаблони + редактор тексту | Української колекції, підбору за змістом, історій, якісної кирилиці |
| AI-генератори мемів | Генерують підписи до світових шаблонів | Українського контексту, культурної цінності |
| Сторінки «classical art memes» | Ручні меми зі світової класики | Інструмента «зроби сам», українського мистецтва |
| Google Arts & Culture, сайти музеїв | Оцифровані колекції, серйозний тон | Гумору, вірусності, приводу повернутися |
| Українські мем-канали в Telegram | Готові меми щодня | Персоналізації, освітнього шару |
| Генератори зображень (загальні AI) | Нове зображення за запитом | Справжніх картин, фактів, зв'язку з культурою |

**Позиціонування:** перетин трьох речей, якого ніхто не займає: **інструмент створення** (не лише перегляд) + **українська колекція** + **перевірена історія**.

> Для світу мистецтва ми є найвеселішим входом у музей. Для світу мемів ми є єдиним генератором, після якого ти щось дізнався.

## 7. Бізнес-модель і монетизація

**Принцип:** базове створення мемів назавжди безкоштовне і без реєстрації. Це двигун росту й суть місії. Гроші приходять від тих, кому цінна аудиторія, дані або розширені можливості.

### Потоки доходу

| # | Потік | Як працює | Коли | Потенціал |
| :-- | :-- | :-- | :-- | :-- |
| 1 | **Гранти та культурні фонди** | Заявки на розширення колекції, освітні модулі, переклади | 0–6 міс. | Основне фінансування першого року |
| 2 | **Музейні партнерства (B2B)** | Брендована колекція музею на платформі, віджет для сайту музею, QR-коди в залах («зроби мем із цієї картини»), щомісячний звіт про популярність робіт | 6–12 міс. | Найстабільніший дохід |
| 3 | **Брендовані кампанії** | Тематичні добірки та челенджі зі спонсором («Тиждень кави з Пимоненком»), підписи в тоні бренду | 6–12 міс. | Найвищий разовий чек |
| 4 | **Мерч на вимогу** | Кнопка «Надрукувати»: листівка, стікерпак, футболка, чашка з власним мемом через print-on-demand партнера | 3–9 міс. | Маржа з кожного замовлення, нуль складу |
| 5 | **Освітній пакет** | Набір для вчителя: готові уроки, клас без реклами, добірки за програмою, завдання й рейтинг класу | 6–12 міс. | Ліцензії школам або фінансування через гранти |
| 6 | **Преміум для авторів** | Без водяного знака, HD-експорт, пакетне створення, власні шрифти, історія та папки, пріоритетний AI | 9–15 міс. | Невеликий чек, багато користувачів |
| 7 | **Telegram-монетизація** | Преміум-стікерпаки, оплата через Telegram Stars, платні «ще варіанти» понад ліміт | 6–12 міс. | Мікроплатежі |
| 8 | **API та ліцензування даних** | Доступ до підбору картин і мем-профілів для медіа, застосунків, освітніх платформ | 12+ міс. | Довгострокова опція |

**Чого свідомо не робимо:** банерну рекламу (руйнує музейну естетику та довіру) і продаж персональних даних.

### Орієнтовні пакети (гіпотеза цін для тестування на інтерв'ю)

| Пакет | Для кого | Що входить | Ціна (перевірити) |
| :-- | :-- | :-- | :-- |
| Безкоштовний | Усі | Усе базове, водяний знак, ліміт AI-запитів на день | 0 |
| Автор | SMM, адміни каналів | Без водяного знака, HD, пакетний режим, більше AI-запитів | 99–149 грн/міс. |
| Клас | Вчителі | Простір класу, добірки за програмою, плани уроків | Безкоштовно для вчителя; оплата школою або грантом |
| Музей | Інституції | Власна колекція, віджет, QR-сценарій, аналітика | Пілот безкоштовно, далі від 5–15 тис. грн/міс. |
| Кампанія | Бренди | Тематична добірка, челендж, звіт | Від 30–80 тис. грн за кампанію |

### Послідовність

1. **Місяці 0–3:** без доходу. Збір метрик і доказів попиту, подача 2–3 грантових заявок.
2. **Місяці 3–6:** перший музейний пілот (безкоштовний, в обмін на кейс і відгук), тест мерчу.
3. **Місяці 6–12:** платні музейні пакети, перша брендована кампанія, освітній пакет.
4. **Місяці 12+:** преміум-підписка, API, вихід на діаспору та англомовну версію.

## 8. Unit-економіка

### Вартість одного мема

| Стаття | Розрахунок | Орієнтир |
| :-- | :-- | :-- |
| AI, «Фраза → Картина» (MVP) | ~6 000 токенів на запит (LLM бачить увесь компактний каталог) | Частки цента — кілька центів залежно від моделі |
| AI, «Фраза → Картина» (з векторним пошуком) | Ембединг фрази + LLM-реранк топ-кандидатів; вартість не росте з розміром колекції | У кілька разів дешевше за MVP |
| AI, «Картина → Підпис» | Підписи беруться із заздалегідь згенерованого пулу; живий виклик лише для «Ще варіанти» | Близько нуля |
| Повторні фрази | Кеш за нормалізованою фразою | 0 |
| Інфраструктура | Безкоштовні тарифи на старті; далі фіксована місячна плата | Див. розділ 16 |

**Формула для дашборда:**

```
Вартість завершеного мема = (витрати на AI за період + інфраструктура за період) / кількість завершених мемів
```

**Ціль:** менше 0,01 $ за завершений мем після ввімкнення векторного пошуку та кешу. Фактичне число брати з логів токенів, які вже передбачені планом (Person A логує використання на кожен виклик).

**Запобіжники витрат, уже закладені в архітектуру:** ліміт запитів на IP, денна стеля бюджету, після перевищення — лише векторний пошук без LLM, 8-секундний тайм-аут із запасним підбором за тегами.

### Економіка користувача (гіпотези)

| Показник | Як рахуємо | Гіпотеза |
| :-- | :-- | :-- |
| CAC органічний | Витрати на контент і ком'юніті / нові активовані користувачі | Близько 0 (час команди) |
| CAC платний | Рекламний бюджет / нові активовані користувачі | Тестувати малими бюджетами; не масштабувати, доки K-фактор < 0,3 |
| Мемів на користувача за місяць | Завершені меми / MAU | 3–5 |
| Витрати на користувача за місяць | Мемів × вартість мема | Менше 0,05 $ |
| Дохід на користувача (B2C) | Конверсія в преміум × ціна + маржа мерчу | Низький; B2C не є основним джерелом доходу |
| Дохід B2B | Кількість партнерів × середній чек | Основне джерело |

**Висновок:** продукт дешевий у обслуговуванні, тому головне питання не «чи покриє користувач свою вартість», а «чи набереться достатня аудиторія, щоб бути цінною для музеїв, грантодавців і брендів».

## 9. North Star Metric і дерево метрик

### North Star Metric

> **Кількість завершених мемів на тиждень (Weekly Completed Memes, WCM)**
>
> *Завершений мем* — це мем, який користувач **завантажив, поширив, зберіг у «Мої меми» або отримав готовим у Telegram-боті й переслав чи зберіг.*

**Чому саме вона:**

| Критерій | Як WCM його виконує |
| :-- | :-- |
| Відображає цінність для користувача | Людина довела мем до кінця, отже результат їй сподобався |
| Відображає місію | Кожен завершений мем означає показану історію про картину та художника |
| Є випереджальним індикатором росту | Кожен мем із водяним знаком потрапляє в чат і приводить нових людей |
| Є випереджальним індикатором доходу | Музеям і брендам продається саме обсяг контактів із мистецтвом |
| Команда може на неї впливати | Якість підбору, швидкість, зручність редактора, кнопки поширення |
| Проста | Одне число, зрозуміле всім без пояснень |

**Чому не інші:**

- *MAU/відвідувачі* — можна наростити рекламою без жодної цінності.
- *Згенеровані меми* — рахує й невдалі результати, які користувач відкинув.
- *Час на сайті* — для нашого продукту швидше означає краще.
- *Перегляди історій* — важливо, але це супутня метрика місії, а не повна цінність.

### Супутня метрика місії

> **Частка завершених мемів із взаємодією з історією** (розгорнув факт, перейшов на сторінку художника чи переслав факт). Відповідає на запитання «чи ми справді наближаємо людей до мистецтва, а не просто робимо меми».

## 10. Воронка AARRR

### Загальна схема

```
ЗАЛУЧЕННЯ      Побачив мем у чаті / пост / QR у музеї / пошук
     │
     ▼
ПЕРШИЙ ВІЗИТ   Відкрив сайт або натиснув /start у боті
     │         ціль: 60% вводять фразу чи обирають картину
     ▼
АКТИВАЦІЯ      Отримав перший мем («ага-момент»: «це ж точно про мене»)
     │         ціль: 85% запитів дають результат за ≤ 10 с
     ▼
ЗАВЕРШЕННЯ     Завантажив / поширив / зберіг        ← North Star
     │         ціль: 35% згенерованих мемів
     ▼
КОНТАКТ        Прочитав факт, перейшов до художника
З МИСТЕЦТВОМ   ціль: 25% завершених мемів
     │
     ▼
УТРИМАННЯ      Повернувся протягом 7 днів
     │         ціль: 20% сайт, 30% бот
     ▼
РЕКОМЕНДАЦІЯ   Його мем привів нового користувача
     │         ціль: K ≥ 0,3
     ▼
ДОХІД          Мерч, преміум, участь у брендованій кампанії, B2B-контакт
```

### Етапи детально

| Етап | Запитання | Ключова метрика | Події | Ціль (гіпотеза) | Важелі покращення |
| :-- | :-- | :-- | :-- | :-- | :-- |
| **Acquisition** (залучення) | Звідки приходять? | Нові унікальні відвідувачі та нові користувачі бота за каналами | `session_start`, `bot_start` з `utm_source` | 60%+ з органіки та вірусності | Водяний знак із адресою, сторінка мема з прев'ю, inline-режим бота |
| **Activation** (активація) | Чи отримали цінність із першого візиту? | Частка нових, що згенерували ≥ 1 мем у першій сесії | `phrase_submitted`, `artwork_selected`, `meme_generated` | ≥ 50% | Приклади фраз на головній, кнопка «Мені пощастить», швидкість, без реєстрації |
| **Completion** (завершення) | Чи результат достатньо добрий, щоб його забрати? | Завершені / згенеровані | `meme_downloaded`, `meme_shared`, `meme_saved`, `bot_meme_forwarded` | ≥ 35% | Якість підбору, «Інша картина», редактор на мобільному, кнопки поширення в один дотик |
| **Art engagement** (контакт із мистецтвом) | Чи дізналися щось? | Частка мемів із відкритою історією; переходи на сторінки художників | `fact_expanded`, `artist_page_viewed`, `fact_shared` | ≥ 25% | Інтригуючий заголовок факту, факт як окрема картка для пересилання |
| **Retention** (утримання) | Чи повертаються? | W1, W4; мемів на творця за тиждень | `session_start` повторний, `bot_message` | W1 ≥ 20%, W4 ≥ 10% | Мем дня, щотижневі челенджі, сповіщення бота, нові картини, колекція |
| **Referral** (рекомендація) | Чи приводять інших? | K-фактор; частка нових із реферальних джерел | `shared_meme_opened`, `shared_meme_converted` | K ≥ 0,3 | Сторінка мема з кнопкою «Зроби свій», inline-бот, стікерпаки |
| **Revenue** (дохід) | Чи платять? | Дохід на місяць; кількість B2B-партнерів; замовлення мерчу | `merch_clicked`, `premium_started`, B2B у CRM | Див. розділ 16 | Кейси для музеїв, аналітика як продукт, мерч із власного мема |

### Окрема воронка Telegram-бота

```
/start → перша фраза → отриманий мем → переслав у чат → повернувся за 7 днів → додав бота inline у чаті
```

Бот має коротший шлях до цінності (не треба відкривати браузер) і вбудований канал повернення (сповіщення), тому очікуємо в ньому вищу активацію та утримання. Метрики бота рахувати окремо від сайту.

### Воронка B2B (музеї, бренди)

```
Список цільових інституцій → перший контакт → демо з їхніми картинами → безкоштовний пілот (4–6 тижнів)
→ звіт із цифрами → платний договір → продовження
```

| Метрика | Ціль на перші 6 місяців (гіпотеза) |
| :-- | :-- |
| Контактів | 30 |
| Демо | 10 |
| Пілотів | 3 |
| Платних договорів | 1–2 |

## 11. Метрики якості AI та контенту

Якість підбору є головним драйвером частки завершення, тому вимірюється числом, а не на око.

### Якість AI

| Метрика | Як міряємо | Ціль |
| :-- | :-- | :-- |
| **Top-5 hit rate** | Тестовий набір 30–50 фраз, для кожної 2–3 «правильні» картини; частка фраз, де правильна картина в топ-5 | ≥ 80% |
| Частка «Інша картина» | Запити, де користувач попросив заміну / усі запити | ≤ 40% |
| Частка прийнятих AI-підписів | Обрано один із 3 запропонованих / показано | ≥ 50% |
| Частка власних підписів | Користувач написав свій замість запропонованих | Спостерігати; високе значення сигналізує про слабкі підписи |
| Оцінка «смішно» | Реакція 👍/👎 після створення | ≥ 70% позитивних |
| Час відповіді p50 / p95 | Логи бекенду | ≤ 4 с / ≤ 10 с |
| Частка запасного підбору | Запити, що пішли на підбір за тегами | ≤ 5% |
| Частка відмов модерації | Відхилені фрази / усі | Спостерігати; хибні відмови ≤ 1% |

### Якість контенту

| Метрика | Ціль |
| :-- | :-- |
| Картин у колекції | 150 → 500 за 6 міс. → 1 500 за 12 міс. |
| Художників | 16 → 40 за 12 міс. |
| Частка профілів зі статусом «approved» | 100% опублікованих |
| Частка фактів із другим підтвердженням | 100% опублікованих |
| Покриття | Частка картин, з яких створено ≥ 1 мем за місяць ≥ 70% |
| Концентрація | Топ-10 картин ≤ 30% мемів |
| Повідомлень про помилку у факті | Реакція протягом 48 год |

### Метрики впливу (для грантодавців і музеїв)

- Кількість показаних фактів про українських художників.
- Кількість унікальних людей, що відкрили сторінку художника.
- Рейтинг «відкритих» художників: кого найбільше дізналися через меми.
- Переходи на сайт музею-партнера.
- Короткі опитування: «Чи дізналися ви сьогодні нове ім'я?» (частка «так»).

## 12. Залучення користувачів

### Принцип: продукт сам себе поширює

Кожен завершений мем є рекламним носієм. Основна ставка — на **вбудовану вірусність**, а платні канали підключаються лише після підтвердження утримання.

### Вірусні петлі

**Петля 1. Мем у чаті (основна).**

```
Користувач створює мем → надсилає в чат (5–30 людей) → хтось бачить водяний знак «pidsklom» →
→ переходить → створює свій → надсилає в інший чат
```

Що потрібно: читабельний, але ненав'язливий водяний знак із коротким адресом; публічна сторінка мема з прев'ю та великою кнопкою «Зроби свій із цією картиною».

**Петля 2. Inline-бот.**

```
У будь-якому чаті: @бот фраза → мем з'являється прямо в розмові →
→ співрозмовники бачать ім'я бота над повідомленням → пробують самі
```

Найкоротша петля з усіх: нуль переходів. Зараз має пріоритет «Could»; після хакатону підняти до першочергового.

**Петля 3. Факт як привід.**

```
Несподіваний факт → «а ти знав, що…» → пересилання картки факту → перехід на сторінку художника → мем
```

**Петля 4. Стікерпаки.** Найкращі меми тижня виходять стікерпаком у Telegram; кожен стікер веде до бота.

**Розрахунок K-фактора:**

```
K = (частка творців, що поширили) × (середня кількість людей, що побачили) × (конверсія перегляду в нового творця)
Приклад: 0,5 × 12 × 0,05 = 0,30
```

### Канали

| Канал | Тактика | Вартість | Пріоритет |
| :-- | :-- | :-- | :-- |
| **Telegram** | Власний канал «Мем дня»; посів у мем-каналах і студентських чатах; inline-бот; стікерпаки; взаємні згадки з культурними каналами | Час | 1 |
| **Instagram / TikTok / Threads** | Короткі відео «фраза → картина → факт»; серія «Що насправді відбувається на цій картині»; каруселі «5 мемів із Пимоненка» | Час | 1 |
| **Ситуативний контент** | Меми до подій дня (сесія, перше вересня, свята, погода); швидка реакція як у медіа | Час | 1 |
| **Музеї та культурні медіа** | Спільні публікації; QR-коди біля картин; спільні події до Дня музеїв і Ночі музеїв | Партнерство | 2 |
| **Освіта** | Матеріали для вчителів у спільнотах освітян; готовий план уроку; майстер-класи | Час | 2 |
| **Студентські спільноти** | Амбасадори в університетах; конкурси мемів факультетів | Мерч як призи | 2 |
| **PR** | Історія «студенти зробили мем-генератор з українських картин» для культурних і технологічних медіа; участь у хакатонах, фестивалях | Час | 2 |
| **Колаборації з авторами** | Блогери з культури, історії, гумору роблять меми зі своєю аудиторією | Бартер, далі бюджет | 3 |
| **SEO** | Сторінки художників і картин як довгий хвіст: «картини Пимоненка», «Мурашко біографія цікаві факти» | Час | 3 |
| **Платна реклама** | Малі тести в Telegram Ads та Meta лише після W1 ≥ 20% і K ≥ 0,3 | Бюджет | 4 |

### Кампанії та механіки

- **Щотижневий челендж.** Одна тема («понеділок», «сесія», «мама дзвонить»), голосування реакціями, переможці потрапляють у стікерпак.
- **«Мем дня».** Щоденна публікація в каналі та на головній: привід повертатися.
- **Календар приводів.** Дні народження художників, річниці картин, День вишиванки, День Незалежності, Шевченківські дні, Ніч музеїв.
- **«Який ти художник?»** Короткий тест, результат якого є карткою для поширення.
- **Музейний квест.** QR біля картини в залі: зроби мем, покажи на касі, отримай листівку.
- **Баттл факультетів чи міст.** Рейтинг за кількістю завершених мемів.
- **Реферальна механіка.** Після N мемів, створених за твоїм посиланням, відкриваються ексклюзивні шрифти чи рамки.

### План запуску

| :-- | :-- | :-- | :-- |

## 13. Утримання та повернення

Генератор мемів є продуктом «за потребою», тому ключове завдання — стати першою асоціацією в момент «треба смішно відреагувати» і давати зовнішні приводи повертатися.

| Механіка | Як працює | На яку метрику впливає |
| :-- | :-- | :-- |
| **Бот завжди під рукою** | Inline-режим у будь-якому чаті; закріплення бота | Частота використання |
| **Мем дня та розсилка бота** | Щоденна або щотижнева картина з фактом; розсилка лише за згодою і з простим вимкненням | W1, W4 |
| **Колекція** | «Ти зробив меми з 7 із 16 художників»; відзнаки за відкриття митців | Мемів на творця, контакт із мистецтвом |
| **Нові надходження** | Щотижня нова порція картин чи новий художник із анонсом | Повернення |
| **Мої меми** | Особиста галерея як причина зареєструватися й повертатися | Частка зареєстрованих, W4 |
| **Челенджі** | Тижневі теми з голосуванням | Повернення, вірусність |
| **Сезонність** | Добірки до сесії, свят, початку навчального року | Піки активності |
| **Персоналізація** | Рекомендації за улюбленим настроєм чи художником | Частка завершення |

**Як міряти:** когортні таблиці W1/W2/W4/W8 окремо для сайту й бота; окремо для зареєстрованих і анонімних; частка «сильних користувачів» (≥ 3 завершені меми на тиждень).

## 14. План аналітики: події

Бекенд уже логує кожен запит (фраза, кандидати, обрана картина, чи замінив, чи зберіг). Цей журнал треба доповнити подіями з фронтенду та бота, щоб зібрати повну воронку.

### Події

| Подія | Коли | Властивості |
| :-- | :-- | :-- |
| `session_start` | Початок сесії на сайті | `platform`, `utm_source`, `utm_medium`, `referrer`, `is_returning` |
| `bot_start` | `/start` у боті | `start_param` (джерело) |
| `phrase_submitted` | Надіслано фразу | `phrase_length`, `platform`, `is_example` |
| `artwork_selected` | Обрано картину в галереї | `artwork_id`, `artist_id`, `source` (галерея, сторінка художника) |
| `meme_generated` | Показано результат | `flow` (A/B), `artwork_id`, `latency_ms`, `used_fallback`, `from_cache` |
| `match_rerolled` | Натиснуто «Інша картина» | `artwork_id_from`, `artwork_id_to`, `reroll_index` |
| `caption_chosen` | Обрано підпис | `source` (AI, власний), `caption_index` |
| `editor_changed` | Зміна в редакторі | `property` (шрифт, розмір, колір, позиція) |
| `meme_downloaded` | Завантажено PNG | `artwork_id`, `platform` |
| `meme_shared` | Натиснуто «Поділитися» | `channel` (Telegram, посилання, інше) |
| `meme_saved` | Збережено в «Мої меми» | `artwork_id` |
| `bot_meme_delivered` | Бот надіслав мем | `flow`, `latency_ms` |
| `fact_expanded` | Розгорнуто історію | `fact_id`, `type` (картина, художник) |
| `artist_page_viewed` | Відкрито сторінку художника | `artist_id`, `source` |

| `feedback_given` | Реакція 👍/👎 | `value`, `artwork_id`, `flow` |
| `moderation_refused` | Фразу відхилено | `reason` |

### Інструменти

- **PostHog** (безкоштовний тариф або власний хостинг) чи **Plausible/Umami** для вебаналітики без cookie-банера.
- Таблиця `events` у Supabase для подій бекенду та бота; дашборд у Metabase або Supabase SQL.
- UTM-мітки для всіх зовнішніх посилань; параметр `start` у посиланнях на бота.

### Приватність

- Фрази користувачів можуть містити особисте: не пов'язувати їх з акаунтом без потреби, обмежити строк зберігання сирих фраз, для аналізу використовувати знеособлені дані.
- Чітка політика приватності українською; розсилки бота лише за згодою.

### Ритм роботи з метриками

| Частота | Що дивимося |
| :-- | :-- |
| Щодня | WCM за день, помилки, час відповіді, витрати на AI |
| Щотижня | NSM і вхідні метрики, воронка за каналами, top-5 hit rate, топ і антитоп картин |

## 20. Тези для пітчу

**Одне речення:** «Українське мистецтво через гумор: напиши фразу — отримай мем і історію за ним».

**Структура на 3 хвилини:**

1. **Проблема.** Українське мистецтво здається далеким і шкільним; більшість не назве п'ять українських художників.
2. **Інсайт.** Люди не шукають лекцій, але щодня надсилають меми. Мем є найкоротшим шляхом до уваги.
3. **Рішення.** Демо: фраза → картина → факт. 10 секунд, без реєстрації, сайт і Telegram.
4. **Чому це працює.** Підбір за емоцією, а не за предметами. AI не вигадує фактів. Тільки суспільне надбання.
5. **Метрика.** North Star — завершені меми на тиждень: кожен означає контакт людини з українським мистецтвом і безкоштовну рекламу продукту.
6. **Ріст.** Водяний знак, inline-бот, челенджі, музеї. Розповсюдження вбудоване в продукт.
7. **Гроші.** Музеї, гранти, бренди, мерч. Обслуговування коштує центи; один партнер покриває інфраструктуру.
8. **Що далі.** 500 картин, музейний пілот, освітній модуль; далі модель для мистецтва інших країн.

**Запитання журі, до яких варто підготуватися:**
