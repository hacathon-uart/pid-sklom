# Vendored design skills

These two project-local skills come from https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (main, retrieved 2026-11-18):

- `ui-ux-pro-max`
- `design-system`

The upstream MIT license is in `UPSTREAM_LICENSE.txt` and applies to the vendored skill files, not to the original Pid Sklom project. The `SKILL.md` examples were adjusted to use Python 3 and paths under this repository’s `.agents/skills/` directory.

Use their guidance with the existing desktop Figma and `frontend/src/styles/tokens.css` as the project visual source of truth. Do not generate a parallel design system as part of installation.
